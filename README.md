# 💼 Data Science Job Roles and Salaries (2020–2022)

This project involves **data exploration and analysis of job roles and salaries in the Data Science field** between 2020 and 2022. The analysis was performed using **SQL** to extract insights on industry trends, job titles, locations, and compensation.

## 📌 Objectives

- Explore data science-related roles and their salary distribution
- Identify top-paying job titles and regions
- Analyze job growth patterns over a 3-year period

## 🛠️ Tools & Technologies

- **SQL** (Structured Query Language)
- PostgreSQL / MySQL (or specify DBMS used)
- CSV file as the data source
- DB Browser / pgAdmin (optional: specify your environment)

## 📊 Key Insights

- Top-paying data science roles in 2022
- Countries with the highest average salaries
- Year-over-year salary trends
- Remote vs on-site job comparisons (if applicable)
